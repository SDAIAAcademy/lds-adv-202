# تقييم نضج البيانات والذكاء الاصطناعي وخرائط الطريق

Data and AI Maturity Assessment and Roadmaps

مسار التنفيذيين والقادة · أكاديمية سدايا · LDS-ADV-202 · المستوى 200

REPLACE: سطر واحد تحت العنوان: ما يستطيع المشارك فعله بعد المقرر

يُجري المشاركون تقييمًا لنضج البيانات والذكاء الاصطناعي في جهة افتراضية لخدمات المياه: يخططون للأدلة، ويجرون مقابلتين مع مديرَين في تمثيل للأدوار، ويراجعون حزمة وثائق واستبانة للموظفين، ويمنحون كل بُعد درجة مبنية على أدلة متقاطعة المصادر. ثم يحوّلون الفجوات إلى خارطة طريق مرتبة بحسب الأفق الزمني، ويعرضونها على الراعي. أما تدقيق الامتثال لمواصفات البيانات الوطنية فيتناوله المقرر LDS-DMG-207.

**الصيغة:** ورشة عمل: يومان مع مختبرات ومهمة متابعة متعقَّبة

**صفحة المقرر:** https://sdaiaacademy.github.io/lds-adv-202/

## نواتج التعلم

| | نواتج التعلم | المستوى | الدليل |
|---|---|---|---|
| LO1 | يعدّ خطة أدلة تشمل نماذج أسئلة المقابلات وطلب الوثائق واستبانة، وفق نموذج نضج يختاره، استنادًا إلى مقتطفات من ثلاثة نماذج منشورة والهيكل التنظيمي للجهة | Applied | اختيار مبرَّر للنموذج وخطة تربط كل سؤال ببُعد من أبعاده |
| LO2 | يحلل المقابلات والوثائق ونتائج الاستبانة ليمنح كل بُعد درجة مع تقدير لمستوى الثقة، استنادًا إلى مقابلتين و20 وثيقة وبيانات الاستبانة | Applied | ملف درجات بمراجع أدلة يفحص المقيِّم عينة منها |
| LO3 | يصمم خارطة طريق تحوّل الفجوات إلى مبادرات مرتبة بحسب التبعيات والميزانية والقدرة الاستيعابية، استنادًا إلى ملف الدرجات وموجز من الراعي وأرقام القدرة الاستيعابية | Performance | سجل فجوات وخارطة طريق بحسب الأفق الزمني تحدد المسؤولين والمؤشرات |
| LO4 | يعدّ إحاطة للراعي ويقدمها، تعرض النتائج وخارطة الطريق والقرارات المطلوبة، ضمن 15 دقيقة مع راعٍ في تمثيل للأدوار | Applied | عرض تقديمي قصير وإحاطة تُقيَّم بسلم تقدير |
